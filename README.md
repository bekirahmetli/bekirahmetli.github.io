# Bekir Ahmetli Portfolio

Welcome to the personal portfolio website of **Bekir Ahmetli**. This project showcases my skills, projects, and articles as an Android & Java Developer.

## 🌟 Features

- **Multi-Language Support**: Seamlessly switch between Turkish (TR) and English (EN).
- **Responsive Design**: Fully responsive layout that looks great on all devices.
- **Dynamic Content**: JavaScript-based language switching and dynamic text rendering.
- **Sections**:
  - **Hero**: Introduction and role.
  - **About**: Personal information and social links.
  - **Skills**: Technical skills and tools.
  - **Projects**: Showcase of developed applications with GitHub links.
  - **Articles**: Recent technical articles from Medium.
  - **Contact**: Contact form and information.

## 🛠 Technologies Used

- **HTML5**: For semantic structure.
- **CSS3**: For styling and layout.
- **JavaScript**: For logic and interactivity.
  - `language.js`: Handles internationalization (i18n).
  - `main.js`: Main application logic.

## 📂 Project Structure

```
├── css/              # Stylesheets
├── js/               # JavaScript files
├── utils/            # HTML files (Main entry point)
└── README.md         # Project documentation
```

## 🚀 How to Run

1.  Clone the repository.
2.  Navigate to the project directory.
3.  Open `utils/index.html` in your preferred web browser.
